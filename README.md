# UserManagemnetSystem
This is a simple J2EE User Management  System using JSP, Servlet, JDBC, Mysql, JS, CSS

##Features

--Add User
--View  ALL users 
--Update User
--Delete User
--Upload and Display Image
--Image Preview Before Upload
--Looger Implementation
--ServletContextt Usage

##Technologies Used

--JAVA
--JSP
--Servlet
--JDBC
--MySQL
--CSS
--JavaScript
--Apache Tomcat

## Database

Database Name: usersdb

Tables: users

##Project Structure
--Controller -> Servlets
-- Dao-> Database Operations
--Model -> Java Classes
-- JSP ->UI pages

#How to run
-- Import project into eclipse
-- Configure Apache Tomcat
-- Create MySQl database
-- Update database username and password
-- Run the project on server
